Help

How to use Mesh Station on this machine.

Sections

  • Mesh Comms: broadcasts from peers on your network. Reply or save from here.
  • Direct Replies: private replies sent to you. The badge shows unread count.
  • Local AI Pipeline: summarize content with local models.
  • RSS Ingestion: pull in RSS and Atom feeds with tags.
  • Feed Monitor: checks feeds and mesh traffic every 5 minutes for your keywords and sender IDs. Matches appear under Alerts.
  • Saved Cards: bookmarks kept on this device.
  • Apps: open qBittorrent or VLC on this machine.

Layout

  • Collapse the sidebar with the arrow button at the top of it.
  • Change text size with the minus and plus buttons in the bottom-right corner. The setting is remembered.
  • Peers and Outbox counts in the sidebar show live network activity.

Session ID

Your identity on the mesh. It changes each time the app restarts.

Troubleshooting

  • Session ID shows Unavailable: the background daemon is not running. Restart Mesh Station.
  • No peers: check that the machines are on the same network and that UDP ports starting at 41873 are open.
  • An app will not open: install it first. Apps can only be opened from the machine running Mesh Station.
